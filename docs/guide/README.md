# Plebeian Reckless user guide

Welcome. This guide walks you through [reckless.plebeian.app](https://reckless.plebeian.app), our test marketplace built on Nostr, Bitcoin, Lightning and Cashu ecash. Every page has a screenshot, so you can see where to click.

Reckless is a test server. Things change fast, and now and then something breaks. If you spot a problem, please open an issue so we can fix it.

## Good to know

- **Test sats only for the wallet and auctions.** The Reckless Cashu mint runs on a fake Lightning backend, so ecash here has no real value. Bid as much as you like.
- **Product checkout goes to the seller.** Products can come from real sellers, and checkout uses each seller's own payment setup. Check before you pay.
- **Your keys stay yours.** You sign in with your own Nostr key, and the site never sees your private key unless you paste it into the Private Key tab yourself.
- **Two looks, on purpose.** Public pages use the dark Arena theme. Your dashboard has its own lighter console theme, which you can change (see [Your storefront](storefront.md#the-dashboard-look)).
