What this build actually does

  • Mint and bid work. A bidder mints fake sats from the demo mint, locks them to the committee key with NUT-11, and commits a Nostr-signed bid carrying only proof references.
  • Refund is implemented but still being finished. When a bid is displaced, the bidder's browser can ask the coordinator to swap the locked proofs back to the bidder's own wallet key. Treat it as under test, not as a guarantee.
  • Seller settlement is not in this build. A closed auction records a winner; no value has moved to the seller here.
  • The sats are worthless. The mint is a FakeWallet mint. Nothing here is redeemable.
  • The committee is one key, not FROST. Four CometBFT validators run on one host, with no FIPS transport. One operator controls all of them. This is not production and not a compliance claim.
  • The monitor is a commit timeline, not a block explorer. The API exposes consensus timestamps for auctions and bids, not the height each event landed in. The page says so where it matters instead of inventing block contents.

The full, denser demo with its own disclosure remains at /.
